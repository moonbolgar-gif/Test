# RISE — мобильное приложение (демо)

Демонстрационная сборка по [`../../docs/SPEC.md`](../../docs/SPEC.md). Экраны настоящие,
данные — имитация. См. [ADR-012 и ADR-013](../../docs/DECISIONS.md).

## Запуск

```bash
npm install          # из корня репозитория
npm start            # или: npm run start -w @rise/mobile
```

Демо совместимо с **Expo Go** — открывается сканированием QR-кода, dev-client собирать не нужно
(ADR-013). Это верно ровно до появления нативного модуля будильника.

```bash
npm run android      # нативная сборка, если она уже нужна
npm run ios
```

## Чего в демо нет

Это не недоделки, а сознательно отложенное — всё перечисленное требует Фазы 0 или бэкенда.

- **Настоящий будильник** (§4.1). Экран сработки открывается вручную. Приложение не разбудит.
  Главный риск проекта; закрывается нативными модулями и проверкой на реальных устройствах.
- **Запись видео-кружка** (§4.3). Кружок — заглушка, композитинга 9:16 нет.
- **Списание денег** (§8). Суммы показываются, Stripe не вызывается.
- **Покупка RISE+** (§8.4). Только через StoreKit / Google Play Billing, в демо заглушка.
- **Бэкенд.** Данные живут в памяти и сбрасываются при перезапуске.
- **Онбординг, разрешения, тестовый будильник** (§6.2), **выбор друзей** (§6.7), **настройки**
  (§6.19), **авторизация** (§6.3).

## Структура

```
src/design/      токены §5.1–5.3, типографика, шрифты
src/components/  базовые компоненты §5.4
src/features/    бизнес-логика по доменам (испытания §6.11)
src/screens/     экраны §6
src/lib/         состояние, форматирование, имитация сервера
src/app/         навигация §6.0
```

Граница, которую держим ради будущей замены моков: экраны не считают деньги и не отсчитывают
время сами — за это отвечает `src/lib/demoServer.ts`, единственный модуль, который заменится
на реальный API-клиент.
